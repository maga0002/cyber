Beoordelingen importeren

Een lijst met per regel een NIST-code en scores. Bestaande scores worden overschreven, lege cellen laten de huidige waarde staan.

  • Code (verplicht) – bijv. PR.AA-01
  • Huidig / Score / Niveau – 0 t/m 5, of n.v.t.
  • Doel – 0 t/m 5
  • Eigenaar, Toelichting – optioneel

Acties importeren

Bevat het bestand een kolom Actie, dan wordt elke regel als verbeteractie toegevoegd.

  • Code – categorie (DE.CM) of subcategorie (DE.CM-01)
  • Actie, Omschrijving, Eigenaar, Status (Open / In uitvoering / Gereed / Geannuleerd), Prioriteit (Hoog / Middel / Laag), Deadline (bijv. 31-12-2026)
